# 💾 Roblox база скамеров и гарантов

Telegram бот с базой скамеров и мошенников, а также списком гарантов на aiogram 3, связанный с Roblox плейсами\

## 🛠 Технологии

Проект написан на современном асинхронном стеке Python:
- **Python 3.12**
- **aiogram 3.x** — для работы с Telegram Bot API (используется Webhook)
- **aiohttp** — веб-сервер для обработки входящих обновлений от Telegram
- **PostgreSQL + asyncpg** — база данных и быстрая драйвер для асинхронной работы с ней

## ✨ Что реализовано

### 👤 Для пользователей
- **Проверка пользователей** — по ID или `@username` (кнопка в меню или команда `/check`) можно узнать статус пользователя:
  - 🔷 **Обычный пользователь** — информации нет в базе
  - 💎 **Гарант** / 🛡 **Проверенный гарант** — с Roblox ником, пруфами, их количеством и сроком действия звания
  - ❌ **Скаммер** — с причиной скама и пруфами
- Результат проверки отправляется картинкой с описанием (отдельная картинка для каждого статуса)
- **Получение ID** — через кнопку выбора объекта (пользователь / канал / группа) бот показывает ID выбранного объекта (используется Telegram request-кнопка)
- **Покупка звания гаранта** через Telegram Stars (XTR):
  - 💎 Гарант — 750⭐
  - 🛡 Проверенный гарант — 1500⭐
  - Пошаговый FSM-флоу: Roblox ник → пруфы → количество пруфов → подтверждение → инвойс → оплата
  - После оплаты звание выдаётся автоматически на 1 месяц, админы получают уведомление о покупке
- **Жалоба на скам** — пошаговый FSM-флоу: ID/@username скаммера → @username (можно пропустить) → причина (текст или фото с описанием). Жалоба уходит всем админам с кнопкой «Занести в базу скама»

### ⚙️ Админ-панель (`/admin`)
- 📈 **Статистика**: всего пользователей, новых за сегодня, активных гарантов, скаммеров, постов
- 💎 **Выдача званий**: гарант / проверенный гарант (на месяц или навсегда) и скаммер (с указанием причины)
- 📩 **Рассылка** сообщений всем пользователям бота (HTML-форматирование)
- ✅ **Обработка жалоб** — подтверждение занесения скаммера в базу прямо из сообщения с жалобой

### 📝 Конструктор постов
- Создание постов с текстом, фото и URL-кнопками (формат: `Текст + url + цвет`, цвета: `danger`, `success`, `primary`)
- Предпросмотр поста перед сохранением
- Сохранение постов в **избранные** с уникальным ID для публикации в других группах/каналах

## 🤖 Команды бота

| Команда | Описание |
|---|---|
| `/start` | Запуск бота, приветствие и главное меню |
| `/me` | Проверить свой статус в базе |
| `/check <id\|@username>` | Проверить пользователя по ID или @username |
| `/id` | Получить ID объекта (пользователь / канал / группа) |
| `/admin` | Открыть админ-панель (только для админов) |

## 🚀 Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Sayzar232/roblox_base_tg_bot.git
   cd roblox_base_tg_bot
   ```

2. **Создайте виртуальное окружение и установите зависимости:**
   ```bash
   python -m venv venv
   venv\Scripts\activate        # Windows
   source venv/bin/activate     # Linux / macOS

   pip install -r requirements.txt
   ```

3. **Создайте базу данных PostgreSQL** (таблицы создаются автоматически при первом запуске).

4. **Скопируйте `.env.example` в `.env`** и заполните переменные:
   ```bash
   cp .env.example .env   # Windows: copy .env.example .env
   ```

5. **Запустите бота:**
   ```bash
   python main.py
   ```

> ⚠️ Бот работает через **Webhook**, поэтому сервер должен быть доступен из интернета по `WEBHOOK_URL` (например, через домен с HTTPS, reverse proxy или туннель типа ngrok).

## 🔑 Переменные окружения

| Переменная | Описание | Пример |
|---|---|---|
| `BOT_TOKEN` | Токен бота от [@BotFather](https://t.me/BotFather) | `123456:AAH...` |
| `WEBAPP_HOST` | Хост веб-сервера aiohttp | `0.0.0.0` |
| `WEBAPP_PORT` | Порт веб-сервера aiohttp | `8080` |
| `WEBHOOK_PATH` | Путь для приёма вебхуков | `/webhook` |
| `WEBHOOK_SECRET` | Секретный токен для проверки вебхуков | `my_secret_string` |
| `WEBHOOK_URL` | Публичный HTTPS-адрес сервера (без пути) | `https://example.com` |
| `DATABASE_URL` | Строка подключения к PostgreSQL | `postgresql://user:pass@host:5432/dbname` |
| `ADMINS_IDS` | ID админов через запятую | `12345678,987654321` |

## 🗄 База данных

Схема создаётся автоматически при старте (`init_db`):

- **`users`** — все пользователи бота (`id`, `username`, `full_name`, `created_at`)
- **`user_garants`** — звания гарантов (`garant_name`, `roblox_username`, `proofs`, `proofs_num`, `purchased_at`, `expires_at`)
- **`user_scammers`** — скаммеры (`reason`, `proofs`, `created_at`)
- **`posts`** — сохранённые посты (`text`, `photo_file_id`, `buttons` в JSONB, `is_favorite`, `created_at`)
